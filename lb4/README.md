# Лабораторная №4 - Карты (map), строки и ввод данных в Go

## Выполненные задания

1. Создана карта (map) с именами людей и их возрастами, добавлена новая запись и выведены все пары ключ-значение на экран.
2. Реализована функция `averageAge`, принимающая карту и вычисляющая средний возраст всех людей с проверкой на пустую карту.
3. Реализовано удаление записи из карты по заданному имени с предварительной проверкой существования ключа.
4. Написана функция считывания строки из стандартного ввода и преобразования её в верхний регистр.
5. Реализовано считывание нескольких чисел, введённых через пробел, и вычисление их суммы с обработкой и пропуском нечисловых значений.
6. Написана функция считывания последовательности целых чисел и вывода их в обратном порядке.

## Требования

- Go 1.20+

## Установка и запуск

Сохраните файл под именем `main.go`, перейдите в каталог с ним и выполните команду:

```bash
go run main.go
```

После запуска программа последовательно выполнит все 6 заданий: выведет содержимое карт, средний возраст, результат удаления записи, а затем по очереди запросит ввод строки и наборов чисел для демонстрации работы функций ввода и обработки данных.

## Задание 1 - Карта с именами и возрастами
Создаётся карта `people := map[string]int`, содержащая имена и возраст трёх человек (`Анна`, `Борис`, `Виктор`). Затем в карту добавляется новая запись `"Галина": 28`, после чего с помощью цикла `for range` выводятся все элементы.

### Пример
Добавление ключа `"Галина"` со значением `28` в карту `people`.

### Ответ
```
--- Задание 1: Карта с именами и возрастами ---
Анна: 25 лет
Борис: 30 лет
Виктор: 22 лет
Галина: 28 лет
```

## Задание 2 - Средний возраст
Реализована функция `averageAge(people map[string]int) float64`, которая проверяет, не пуста ли карта (если пуста — возвращает `0`), суммирует значения возрастов всех записей и делит сумму на количество элементов `len(people)`.

### Пример
Вызов `averageAge(people)` для карты `{"Анна": 25, "Борис": 30, "Виктор": 22}`.

### Ответ
```
--- Задача 2: Средний возраст ---
Средний возраст: 25.67
```

## Задание 3 - Удаление записи по имени
Функция `task3()` проверяет наличие ключа `"Борис"` в карте с помощью конструкции `if _, exists := people[nameToDelete]; exists`. Если запись найдена, она удаляется встроенной функцией `delete`, после чего выводятся оставшиеся записи.

### Пример
Удаление записи с ключом `"Борис"`.

### Ответ
```
--- Задание 3: Удаление записи по имени ---
Удаляем: Борис
Запись удалена.
Оставшиеся записи:
Анна: 25 лет
Виктор: 22 лет
```

### Тест - Запись не найдена
`Удаляем: Дмитрий`

### Ответ
`Запись не найдена.`

## Задание 4 - Строка в верхнем регистре
Функция `task4()` считывает строку из стандартного ввода с помощью `bufio.NewReader(os.Stdin)`, удаляет крайние пробельные символы через `strings.TrimSpace` и переводит текст в верхний регистр функцией `strings.ToUpper`.

### Пример
`Введите строку: Привет, мир!`

### Ответ
`В верхнем регистре: ПРИВЕТ, МИР!`

## Задание 5 - Сумма нескольких чисел
Функция `task5()` считывает строку чисел, разделённых пробелами, разбивает её на подстроки через `strings.Fields` и преобразует каждую в целое число с помощью `strconv.Atoi`. Корректные числа прибавляются к общей сумме, а нечисловые токены пропускаются с выводом предупреждения.

### Пример
`Введите числа через пробел: 10 20 30 5`

### Ответ
`Сумма: 65`

### Тест - Нечисловое значение
`Введите числа через пробел: 10 abc 25`

### Ответ
```
Пропущено нечисловое значение: abc
Сумма: 35
```

## Задание 6 - Массив в обратном порядке
Функция `task6()` считывает целые числа через пробел, отбирает корректно распознанные значения через `strconv.Atoi` в срез `arr`, разворачивает элементы на месте с помощью двух указателей и выводит итоговый срез.

### Пример
`Введите целые числа через пробел: 1 2 3 4 5`

### Ответ
`В обратном порядке: [5 4 3 2 1]`

### Тест - Нечисловые элементы во вводе
`Введите целые числа через пробел: 10 текст 20 30`

### Ответ
`В обратном порядке: [30 20 10]`

## Исходный код

```go
package main

import (
	"bufio"
	"fmt"
	"os"
	"strconv"
	"strings"
)

// Функция среднего возраста
func averageAge(people map[string]int) float64 {
	if len(people) == 0 {
		return 0
	}
	sum := 0
	for _, age := range people {
		sum += age
	}
	return float64(sum) / float64(len(people))
}

func task1() {
	fmt.Println("\n--- Задание 1: Карта с именами и возрастами ---")
	people := map[string]int{
		"Анна":   25,
		"Борис":  30,
		"Виктор": 22,
	}

	people["Галина"] = 28

	for name, age := range people {
		fmt.Printf("%s: %d лет\n", name, age)
	}
}

// Удаление записи по имени
func task3() {
	fmt.Println("\n--- Задание 3: Удаление записи по имени ---")
	people := map[string]int{
		"Анна":   25,
		"Борис":  30,
		"Виктор": 22,
	}

	nameToDelete := "Борис"
	fmt.Printf("Удаляем: %s\n", nameToDelete)

	if _, exists := people[nameToDelete]; exists {
		delete(people, nameToDelete)
		fmt.Println("Запись удалена.")
	} else {
		fmt.Println("Запись не найдена.")
	}

	fmt.Println("Оставшиеся записи:")
	for name, age := range people {
		fmt.Printf("%s: %d лет\n", name, age)
	}
}

// Вывод строки в верхнем регистре
func task4() {
	fmt.Println("\n--- Задание 4: Строка в верхнем регистре ---")
	reader := bufio.NewReader(os.Stdin)
	fmt.Print("Введите строку: ")
	input, _ := reader.ReadString('\n')
	input = strings.TrimSpace(input)
	fmt.Println("В верхнем регистре:", strings.ToUpper(input))
}

// Сумма нескольких чисел
func task5() {
	fmt.Println("\n--- Задание 5: Сумма чисел ---")
	reader := bufio.NewReader(os.Stdin)
	fmt.Print("Введите числа через пробел: ")
	input, _ := reader.ReadString('\n')
	input = strings.TrimSpace(input)

	fields := strings.Fields(input)
	sum := 0
	for _, f := range fields {
		num, err := strconv.Atoi(f)
		if err != nil {
			fmt.Printf("Пропущено нечисловое значение: %s\n", f)
			continue
		}
		sum += num
	}
	fmt.Printf("Сумма: %d\n", sum)
}

// Массив в обратном порядке
func task6() {
	fmt.Println("\n--- Задание 6: Массив в обратном порядке ---")

	reader := bufio.NewReader(os.Stdin)
	fmt.Print("Введите целые числа через пробел: ")
	input, _ := reader.ReadString('\n')
	input = strings.TrimSpace(input)

	fields := strings.Fields(input)
	arr := make([]int, 0, len(fields))
	for _, f := range fields {
		if num, err := strconv.Atoi(f); err == nil {
			arr = append(arr, num)
		}
	}

	for i, j := 0, len(arr)-1; i < j; i, j = i+1, j-1 {
		arr[i], arr[j] = arr[j], arr[i]
	}
	fmt.Println("В обратном порядке:", arr)
}

func main() {
	task1()

	fmt.Println("\n--- Задача 2: Средний возраст ---")
	people := map[string]int{
		"Анна":   25,
		"Борис":  30,
		"Виктор": 22,
	}
	fmt.Printf("Средний возраст: %.2f\n", averageAge(people))

	task3()
	task4()
	task5()
	task6()
}
```
