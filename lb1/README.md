# Лабораторная №1 - Работа с переменными и числами Go

## Выполненные задания

- Написана программа, которая выводит текущее время и дату.
- Созданы переменные различных типов (int, float64, string, bool) и реализован их вывод на экран.
- Использована краткая форма объявления переменных для создания и вывода переменных.
- Написана программа для выполнения арифметических операций с двумя целыми числами и выводом результатов.
- Реализована функция для вычисления суммы и разности двух чисел с плавающей запятой.
- Написана программа, которая вычисляет среднее значение трех чисел.

## Требования

- Go 1.20+

## Установка и запуск

Сохраните файл под именем lb1.go, перейдите в каталог с ним и выполните команду:

```bash
  go run lb1.go
```
При корректном запуске программа выведет все задания с результатами.

| Файл | Назначение |

## Задание 1 - Время и дата
Получает текущее время и дату с помощью time.Now() и выводит их в заданном формате.

### Ответ
`Дата и время: 01.09.2026 14:23:31`

## Задание 2 - Работа с переменными различных типов
Объявляет переменные четырёх базовых типов (int, float64, string, bool) через var с явным указанием типа и выводит их на экран.

### Ответ
```
int: 10
float64: 3.14
string: Привет
bool: true
```

## Задание 3 - Краткая форма объявления переменных
Создаёт переменные через оператор :=, при котором тип выводится автоматически.

### Ответ
```
x = 5
y = 2.5
name = Go
ok = false
```

## Задание 4 - Арифметические операции с целыми числами
Выполняет сложение, вычитание, умножение, целочисленное деление и остаток от деления.

### Пример 
`a := 17
c := 5`

### Ответ

```
Сложение: 22
Вычитание: 12
Умножение: 85
Деление: 3
Остаток: 2
```

## Задание 5 - Операции с числами с плавающей запятой
Реализованы функции sum и diff, принимающие два аргумента типа float64.

### Пример 
`10.5, 4.2`

### Ответ
```
Сумма: 14.7
Разность: 6.3
```

## Задание 6 - Среднее значение трех чисел
Реализована функция average, вычисляющая среднее арифметическое трёх чисел типа float64.

### Пример 
`4, 7, 10`

### Ответ
`Среднее: 7`

## Исходный код

```go
package main

import (
	"fmt"
	"time"
)

func sum(a, b float64) float64 {
	return a + b
}

func diff(a, b float64) float64 {
	return a - b
}

func average(a, b, c float64) float64 {
	return (a + b + c) / 3
}

func main() {

	fmt.Println("=== Задание 1 ===")
	now := time.Now()
	fmt.Println("Дата и время:", now.Format("02.01.2006 15:04:05"))

	fmt.Println("\n=== Задание 2 ===")
	var i int = 10
	var f float64 = 3.14
	var s string = "Привет"
	var b bool = true
	fmt.Println("int:", i)
	fmt.Println("float64:", f)
	fmt.Println("string:", s)
	fmt.Println("bool:", b)

	fmt.Println("\n=== Задание 3 ===")
	x := 5
	y := 2.5
	name := "Go"
	ok := false
	fmt.Println("x =", x)
	fmt.Println("y =", y)
	fmt.Println("name =", name)
	fmt.Println("ok =", ok)

	fmt.Println("\n=== Задание 4 ===")
	a := 17
	c := 5
	fmt.Println("Сложение:", a+c)
	fmt.Println("Вычитание:", a-c)
	fmt.Println("Умножение:", a*c)
	fmt.Println("Деление:", a/c)
	fmt.Println("Остаток:", a%c)

	fmt.Println("\n=== Задание 5 ===")
	fmt.Println("Сумма:", sum(10.5, 4.2))
	fmt.Println("Разность:", diff(10.5, 4.2))

	fmt.Println("\n=== Задание 6 ===")
	fmt.Println("Среднее:", average(4, 7, 10))
}
```
