# Лабораторная №3 - Пакеты, массивы и срезы в Go

## Выполненные задания

1.	Создан пакет `mathutils` с функцией `Factorial` для вычисления факториала числа с проверкой на переполнение и отрицательные значения.
2.	Реализован ввод числа пользователем в основной программе и вычисление его факториала с помощью пакета `mathutils`.
3.	Создан пользовательский пакет `stringutils` с функцией `Reverse` для переворота строки с учетом символов Юникода (рун) и применен в основной программе.
4.	Написана программа, создающая массив из 5 целых чисел, заполняющая его случайными значениями и выводящая их на экран.
5.	На основе массива создан срез, продемонстрированы операции добавления элемента через `append` и удаления элемента по индексу.
6.	Реализован поиск самой длинной строки в срезе строк с помощью функции `LongestString` из пакета `stringutils`.

## Установка и запуск

Сохраните файлы согласно структуре проекта в директории `lb3`, инициализируйте модуль (`go mod init lb3`), перейдите в каталог с проектом и выполните команду:

```bash
  go run main.go
```

После запуска программа последовательно выполнит все задания: запросит ввод числа для вычисления факториала, затем запросит строку для переворота, после чего автоматически сгенерирует массив, выполнит операции со срезом и найдет самую длинную строку из заданного набора.

## Задание 1 и 2 - Пакет mathutils и вычисление факториала
Создан пакет `mathutils`, содержащий функцию `Factorial(n int) (uint64, error)`. Функция проверяет, что число не отрицательное и не превышает 20 (во избежание переполнения типа `uint64`), после чего в цикле вычисляет факториал. В `main.go` программа считывает число от пользователя, преобразует его в `int` и выводит результат или сообщение об ошибке.

### Пример 
`Введите целое число: 5`

### Ответ
`5! = 120`

### Тест - Превышение
`Введите целое число: 45`

### Ответ
`Ошибка: число слишком большое, результат превысит uint64`

### Тест - Не целое число
`Введите целое число: 4.5`

### Ответ
`Ошибка: введено не целое число`

## Задание 3 - Пакет stringutils и переворот строки
Создан пакет `stringutils` с функцией `Reverse(s string) string`. Строка преобразуется в срез рун `[]rune` для корректной работы с кириллицей, после чего элементы разворачиваются в обратном порядке. В `main.go` программа считывает строку от пользователя и выводит её перевёрнутую версию.

### Пример 
`Введите строку: привет`

### Ответ
`Перевёрнутая строка: тевирп`

## Задание 4 - Массив из 5 целых чисел
Программа объявляет массив `var arr [5]int`, заполняет его случайными числами от 0 до 99 с помощью `rand.Intn(100)` и выводит как поэлементно с индексами, так и в одну строку.

## Задание 5 - Работа со срезом
На базе созданного массива формируется срез `slice := arr[:]`. С помощью встроенной функции `append` в конец среза добавляется число `999`, а затем удаляется элемент с индексом `2` путём объединения частей среза до и после удаляемого элемента.

### Пример 
Добавление значения `999` и удаление элемента по индексом `2`.

### Ответ
```
=== 4. Работа со срезом ===
Исходный срез: [81 87 47 59 81] 
После append(999): [81 87 47 59 81 999] 
После удаления элемента с индексом 2: [81 87 59 81 999] 
```

## Задание 6 - Поиск самой длинной строки
В пакет `stringutils` добавлена функция `LongestString(strs []string) string`, которая перебирает срез строк и сравнивает их длину в рунах `len([]rune(s))`. В `main.go` передаётся срез `[]string{"привет", "бронетранспортер", "привычка", "котенок", "ответ"}` и выводится найденное слово вместе с его длиной.

### Пример 
`Срез строк: [привет бронетранспортер привычка котенок ответ]`

### Ответ
`Самая длинная строка: "бронетранспортер" (длина = 16)`

```go
package main

import (
	"bufio"
	"fmt"
	"math/rand"
	"os"
	"strconv"
	"strings"

	"lb3/mathutils"
	"lb3/stringutils"
)

func main() {
	reader := bufio.NewReader(os.Stdin)

	// Задание 2: факториал введённого числа
	fmt.Println("=== 1. Вычисление факториала ===")
	fmt.Print("Введите целое число: ")
	input, _ := reader.ReadString('\n')
	input = strings.TrimSpace(input)

	n, err := strconv.Atoi(input)
	if err != nil {
		fmt.Println("Ошибка: введено не целое число")
	} else {
		fact, err := mathutils.Factorial(n)
		if err != nil {
			fmt.Printf("Ошибка: %v\n", err)
		} else {
			fmt.Printf("%d! = %d\n", n, fact)
		}
	}

	// Задание 3: переворот строки
	fmt.Println("\n=== 2. Переворот строки ===")
	fmt.Print("Введите строку: ")
	str, _ := reader.ReadString('\n')
	str = strings.TrimRight(str, "\r\n")
	fmt.Printf("Перевёрнутая строка: %s\n", stringutils.Reverse(str))

	// Задание 4: массив из 5 целых чисел
	fmt.Println("\n=== 3. Массив из 5 целых чисел ===")
	var arr [5]int

	for i := 0; i < len(arr); i++ {
		arr[i] = rand.Intn(100)
		fmt.Printf("arr[%d] = %d\n", i, arr[i])
	}

	fmt.Print("Массив: ")
	for _, v := range arr {
		fmt.Printf("%d ", v)
	}
	fmt.Println()

	// Задание 5: срез из массива, добавление и удаление
	fmt.Println("\n=== 4. Работа со срезом ===")
	slice := arr[:]
	fmt.Printf("Исходный срез: %v \n", slice)

	// Добавление элемента
	slice = append(slice, 999)
	fmt.Printf("После append(999): %v \n", slice)

	// Удаление элемента по индексу 2
	indexToRemove := 2
	if indexToRemove >= 0 && indexToRemove < len(slice) {
		slice = append(slice[:indexToRemove], slice[indexToRemove+1:]...)
		fmt.Printf("После удаления элемента с индексом %d: %v \n",
			indexToRemove, slice)
	}

	// Задание 6: самая длинная строка в срезе
	fmt.Println("\n=== 5. Поиск самой длинной строки ===")
	words := []string{"привет", "бронетранспортер", "привычка", "котенок", "ответ"}
	fmt.Printf("Срез строк: %v\n", words)
	longest := stringutils.LongestString(words)
	fmt.Printf("Самая длинная строка: %q (длина = %d)\n", longest, len([]rune(longest)))
}
```

### `mathutils/mathutils.go`
```go
package mathutils

import "errors"

func Factorial(n int) (uint64, error) {
	if n < 0 {
		return 0, errors.New("факториал отрицательного числа не определён")
	}
	if n > 20 {
		return 0, errors.New("число слишком большое, результат превысит uint64")
	}

	result := uint64(1)
	for i := 2; i <= n; i++ {
		result *= uint64(i)
	}
	return result, nil
}
```

### `stringutils/stringutils.go`
```go
package stringutils

func Reverse(s string) string {
	runes := []rune(s)
	for i, j := 0, len(runes)-1; i < j; i, j = i+1, j-1 {
		runes[i], runes[j] = runes[j], runes[i]
	}
	return string(runes)
}

func LongestString(strs []string) string {
	if len(strs) == 0 {
		return ""
	}
	longest := strs[0]
	for _, s := range strs[1:] {
		if len([]rune(s)) > len([]rune(longest)) {
			longest = s
		}
	}
	return longest
}
```
